### 1. MAPPERS (DLMS_BUSINESS)
Vous devez mettre à jour les mappers AutoMapper :

#### CompteurMappingProfile.cs
Supprimer le mapping de PosteId si présent

#### EquipementMappingProfile.cs  
Ajouter le mapping de PosteId :
`csharp
CreateMap<EquipementAddCommand, Equipement>()
    .ForMember(dest => dest.PosteId, opt => opt.MapFrom(src => src.PosteId));

CreateMap<EquipementEditCommand, Equipement>()
    .ForMember(dest => dest.PosteId, opt => opt.MapFrom(src => src.PosteId));

CreateMap<Equipement, EquipementResponse>()
    .ForMember(dest => dest.PosteId, opt => opt.MapFrom(src => src.PosteId));
`

### 2. CONFIGURATION BASE DE DONNÉES (DLMSDBContext.cs)
Ajouter la configuration de la relation Equipement-Poste dans OnModelCreating :

`csharp
modelBuilder.Entity<Equipement>(entity =>
{
    // ... configuration existante ...
    
    entity.Property(e => e.PosteId).HasColumnName("poste_id");
    
    entity.HasOne(d => d.Poste)
        .WithMany(p => p.Equipements)
        .HasForeignKey(d => d.PosteId)
        .OnDelete(DeleteBehavior.SetNull)
        .HasConstraintName("FK_Equipement_Poste");
});
`
